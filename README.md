# Internship-Of-Data-Analytics
Task 1 – Data Immersion &amp; Wrangling | ApexPlanet 60-Day Data Analytics Internship This project focuses on understanding, profiling, cleaning, and transforming a raw dataset into an analysis-ready dataset. It includes data quality assessment, handling missing values and duplicates, standardizing data formats, feature engineering,.
DATA DICTIONARY
| Field Name        | Data Type     | Description                                           | Example Value | Business Relevance                                              |
| ----------------- | ------------- | ----------------------------------------------------- | ------------- | --------------------------------------------------------------- |
| **Order_ID**      | String        | Unique identifier assigned to each order/transaction. | ORD100002     | Used to identify and track individual orders.                   |
| **Order_Date**    | Date          | Date on which the order was placed.                   | 2025-02-25    | Used for monthly, quarterly, and yearly sales trend analysis.   |
| **Customer_ID**   | String        | Unique identifier assigned to a customer.             | CUST5529      | Used to identify and analyze individual customers.              |
| **Customer_Name** | String        | Name of the customer associated with the order.       | Customer Name | Used for customer-level analysis and identification.            |
| **Age**           | Float/Integer | Age of the customer at the time of the transaction.   | 35            | Helps analyze purchasing patterns across different age groups.  |
| **Gender**        | String        | Gender of the customer.                               | Female        | Enables comparison of purchasing behavior across gender groups. |
| **City**          | String        | City associated with the customer.                    | Agra          | Helps analyze geographical sales and customer distribution.     |
| **Product**       | String        | Name of the product purchased.                        | Laptop        | Used to identify top-selling and underperforming products.      |
| **Category**      | String        | Category to which the purchased product belongs.      | Electronics   | Helps compare sales performance across product categories.      |
| **Quantity**      | Integer       | Number of units purchased in the order.               | 7             | Measures sales volume and customer purchase quantity.           |
| **Unit_Price**    | Float         | Price of one unit of the purchased product.           | 2829.77       | Used to calculate revenue and analyze product pricing.          |
| **Total_Sales**   | Float         | Total revenue generated from the order.               | 19808.39      | Key metric for measuring sales and revenue performance.         |
